# pg_settings_map

Интерактивный HTML-прототип карты параметров PostgreSQL в духе FreeMind.

Откройте `index.html` в современном браузере. Сборка, сервер, установка зависимостей и подключение к PostgreSQL не нужны.

- Три рабочих уровня: группы → подгруппы → параметры.
- Перетаскивание узла переносит его ветку. Дочерние узлы можно двигать отдельно в любую сторону.
- Кнопки +/− сворачивают и раскрывают ветку, сохраняя её текущее расположение.
- Перетаскивание фона перемещает карту. Колесо и кнопки управляют масштабом; «Вписать» показывает все видимые узлы.
- Выбор параметра открывает справку справа (на узком экране — под картой).
- Клавиатура: Tab — выбор элемента; Enter/пробел — открыть справку; стрелки на узле — сдвинуть ветку.
- «Сбросить карту» восстанавливает исходное расположение.

Включены 3 группы, 6 подгрупп и 12 параметров с демонстрационными характеристиками PostgreSQL 17 (стандартная сборка с блоком 8 kB). Это не данные работающего сервера. Значения по умолчанию могут зависеть от сборки и конфигурации.

Координаты существуют только в памяти страницы. Загрузка пользовательского JSON, сохранение координат и логические связи между параметрами — следующие этапы.

## Модель следующего этапа

Узел имеет стабильный `id`, `parent`, `kind`, `label`, координаты `x/y` и характеристики параметра. Пользовательский JSON можно преобразовать в этот формат после знакомства с его структурой. Координаты и состояние веток можно сохранять отдельно по ID (например, в localStorage с экспортом/импортом JSON), не меняя справочник параметров. SVG-связи уже пересчитываются по фактическим координатам и размерам узлов.

## Полная карта из реальных данных

- `pg_settings.json` — исходный загруженный файл, сохранённый без изменений.
- `pg_settings_full.html` — автономная карта по этому файлу: 17 верхних групп, 36 подгрупп и 436 параметров. Открывается в браузере без сервера и сетевых запросов; JSON встроен в HTML.
- `index.html` — первоначальный небольшой демонстрационный вариант.

Полная карта начинает со свёрнутых верхних групп. Кнопка + раскрывает ветку, поиск по имени раскрывает путь и переводит карту к выбранному узлу. Enter выбирает первый результат, Escape очищает поиск. При раскрытии ветки карта автоматически перерасполагает видимые узлы, сохраняя ручные смещения. «Раскрыть всё» показывает обзор всех 490 узлов; для чтения отдельных веток используйте масштабирование или поиск. «Свернуть всё» возвращает обзор групп. «Сбросить карту» также удаляет ручные смещения.

Справка отдельно показывает `setting` и `boot_val`, тип, единицы, границы, контекст, источник, `pending_restart`, перечисляемые значения и дополнительное описание при наличии. Null отображается как «—», пустая строка — как «(пустая строка)». Числовые значения не конвертируются; единицы приводятся отдельно, как в JSON. Версия сервера в файле не указана. Некоторые группы содержат параметры напрямую: исходная иерархия сохранена.

После изменения JSON пересоберите автономный HTML стандартным Python 3:

```sh
cd /workspace/pg_settings_map
python3 tools/build_full_map.py
```

Генератор использует оформление и взаимодействия из `index.html`, добавляет полную модель данных, поиск и автоматическое расположение. Браузерные проверки выполнены для раскрытия всех узлов, поиска, справки, перетаскивания, сохранения ручных смещений при перерасположении, сброса и узкого экрана. Постоянное сохранение координат пока не реализовано.

### Компактный вид и видимость групп

В полной карте слева находится панель всех 17 верхних групп. При открытии страницы все чекбоксы включены. Снятие чекбокса скрывает всю ветку, исключает её из поиска и освобождает место при автоматическом расположении. Повторное включение восстанавливает состояние раскрытия и ручные смещения. «Раскрыть всё» и «Сбросить карту» учитывают текущие фильтры; сброс не включает скрытые группы. Если скрыт выбранный параметр, справка переключается на корень карты. На узких экранах панель располагается над картой и может сворачиваться заголовком «Группы».

Параметры размещаются с промежутком 8 px между элементами вместо прежнего шага 76 px. Высота узла измеряется с учётом переноса длинных имён, чтобы они не перекрывались. Видимость групп, как и координаты, пока действует до перезагрузки страницы.

### Выдвижные панели

В полной карте список групп первоначально убран влево. Кнопка «☰ Группы» открывает панель, «← Скрыть группы» убирает её обратно. Выбранные чекбоксы при этом сохраняются. На узком экране список выезжает поверх карты.

Справка первоначально скрыта и открывается справа поверх карты двойным щелчком по имени параметра. Одиночный щелчок выбирает узел, поиск переводит к нему, но не открывает панель. Щелчок по пустому месту карты закрывает справку; перетаскивание фона её не закрывает. Для клавиатуры: Enter или пробел на параметре открывает справку, Escape закрывает. Панели не требуют постоянного места справа и слева; первоначальный небольшой `index.html` остаётся демонстрацией прежнего варианта.

Управление полной картой находится в верхней панели рядом с названием: поиск, переключатель групп, сворачивание, раскрытие и сброс. Дублирующий заголовок внутри карты и счётчик в шапке удалены. Результаты поиска выпадают под полем поверх карты. На узких экранах элементы управления переносятся на следующие строки шапки; карта занимает оставшуюся высоту экрана.

Справка оформлена компактно: декоративный значок убран, характеристики показываются строками «название — значение», с уменьшенными отступами. Длинные значения переносятся внутри своей колонки, чтобы сохранять читаемость без горизонтальной прокрутки.

### Фокус при раскрытии ветки

Раскрытие группы или подгруппы плавно центрирует выбранный узел вместе с его непосредственными дочерними пунктами. Общая карта при этом не вписывается в экран. Длинные списки сохраняют читаемый масштаб (на широком экране не менее 85%); оставшуюся часть можно просмотреть перетаскиванием фона. На узком экране масштаб дополнительно ограничен шириной ветки. Сворачивание центрирует узел с текущим масштабом. Ручное перемещение и масштабирование прерывают анимацию. Настройка системы «уменьшение движения» отключает анимацию. Кнопки «Вписать» и «Раскрыть всё» сохраняют режим общего обзора.

В автоматическом расположении узлы левых веток выровнены по правому краю, а правых — по левому. Ширина измеряется по фактическому содержимому, включая кнопки и маркеры; текст многострочных левых узлов также выровнен вправо. Ручные смещения сохраняются и могут нарушать автоматическое выравнивание по желанию пользователя.

Инструкции доступны через круглую кнопку «?» внизу слева. Подсказка появляется над кнопкой при наведении или фокусе с клавиатуры; нажатие закрепляет либо скрывает её. Щелчок снаружи или Escape закрывает подсказку. На сенсорном экране используется нажатие.

Двойной щелчок по названию группы или подгруппы переключает раскрытие ветки: первый раскрывает, следующий сворачивает. При этом сохраняются приближение к ветке и ручные смещения. Кнопки +/− продолжают работать; двойной щелчок по параметру открывает справку.
