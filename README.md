# pg_settings_map

Лёгкая интерактивная карта параметров PostgreSQL в духе FreeMind: свободное расположение веток, справка по настройкам, ссылки на документацию QHB, PostgreSQL и статьи The Build.

**Откройте [pg_settings_full.html](pg_settings_full.html) в современном браузере.** Это автономный HTML-файл со встроенными данными. Сборка, сервер, установка зависимостей и подключение к PostgreSQL для просмотра не нужны.

Карта содержит **436 параметров, 17 верхних групп и 36 подгрупп**. Некоторые группы содержат параметры напрямую: сохранена иерархия исходного JSON.

## Возможности

- Свободное перемещение узлов; перемещение родителя переносит его ветку. SVG-линии адаптируются к координатам.
- Двойной щелчок по группе или подгруппе раскрывает и сворачивает её. Кнопки +/− делают то же самое.
- Раскрытая ветка плавно приближается и центрируется вместе с непосредственными дочерними пунктами. Длинные списки сохраняют читаемый масштаб; для просмотра остальных пунктов можно двигать карту.
- Компактные списки параметров с промежутком 8 px. Высота учитывает перенос длинных имён. Левые ветки выровнены по правому краю, правые — по левому.
- Поиск раскрывает путь к узлу и переводит к нему карту.
- Выдвижная панель «Группы» позволяет скрывать верхние ветки чекбоксами. Кнопки «Выбрать все» и «Отменить все» над списком включают или скрывают все группы, сохраняя раскрытие и ручные смещения узлов. По умолчанию скрыты Error Handling, Lock Management, QHB Options, Ungrouped, Developer Options; сама панель убрана. Видимость регулируется только для верхних групп; подгруппы отображаются вместе с родительской веткой. Сохранённый выбор пользователя имеет приоритет над значениями по умолчанию.
- Двойной щелчок по параметру открывает справа компактную справку поверх карты. Щелчок по пустому месту закрывает её; перетаскивание фона не закрывает.
- В карточках доступны ссылки на документацию QHB 1.5.3, официальную документацию PostgreSQL текущего релиза и статьи The Build — в этом порядке. Они открываются в новой вкладке.
- Инструкции доступны в подсказке над кнопкой «?» внизу слева.

Координаты узлов, состояние раскрытия групп и подгрупп и фильтры видимости автоматически сохраняются в `localStorage` браузера и восстанавливаются при следующем открытии страницы. Настройки относятся к этому браузеру и адресу страницы; очистка данных сайта удаляет их. При запрете локального хранилища карта продолжает работать, но настройки между открытиями не сохраняются. Масштаб и положение области просмотра при открытии подбираются заново под размер окна. Карта показывает снимок данных из файла, а не значения подключённого сервера. Версия сервера в исходном JSON не указана.

## Экспорт и импорт настроек

Кнопка «Экспорт» скачивает JSON-файл с именем по умолчанию `pg_settings_map.json`. В нём сохраняются ручные смещения всех узлов, раскрытие групп и подгрупп и их видимость, включая скрытые ветки. Данные параметров PostgreSQL в этот файл не входят.

Кнопка «Импорт» открывает выбор файла. После проверки настройки заменяют текущее состояние карты и автоматически сохраняются в браузере. Узлы сопоставляются по именам и пути в иерархии: неизвестные узлы пропускаются, для отсутствующих в файле используются настройки по умолчанию. Масштаб подбирается под окно. Повреждённый файл, неподдерживаемая версия или файл без узлов этой карты не изменяют текущее состояние; сообщение об ошибке появляется под заголовком. Максимальный размер файла — 2 МБ.

## Управление

| Действие | Управление |
| --- | --- |
| Переместить узел или ветку | Потянуть узел |
| Переместить карту | Потянуть фон |
| Изменить масштаб | Колесо или кнопки +/− внизу |
| Показать видимую карту целиком | «Вписать» |
| Настроить видимость веток | «Группы» и чекбоксы |
| Открыть справку | Двойной щелчок по параметру; Enter/пробел на узле |
| Закрыть справку | Щелчок по пустому месту или Escape |
| Перейти к узлу с клавиатуры | Tab |
| Сдвинуть ветку с клавиатуры | Стрелки на узле |
| Выбрать первый результат поиска | Enter в поле поиска |
| Очистить поиск | Escape в поле поиска |

«Свернуть всё» возвращает обзор групп. «Раскрыть всё» показывает все видимые ветки. «Исходный вид» также удаляет ручные смещения. Эти действия сохраняют выбранные фильтры групп. Поиск включает скрытые группы. При выборе результата его группа становится видимой, путь к узлу раскрывается, а параметр выделяется и получает фокус. Новый выбор видимости автоматически сохраняется. Повторное включение группы сохраняет ручные смещения узлов.

Ручное перемещение и масштабирование прерывают анимацию приближения. Системная настройка уменьшения движения отключает анимацию. На узком экране список групп выезжает поверх карты, а элементы управления переносятся внутри верхней панели. Подсказка «?» доступна по наведению, фокусу и нажатию; щелчок снаружи или Escape закрывает её.

## Справка и источники

Тип параметра показан справа от названия; при недостатке места переносится на следующую строку. Тип и значение из файла выделены одинаковым фоном. Карточка показывает значение из файла (`setting`), значение по умолчанию (`boot_val`), тип, единицы, границы, контекст, источник, необходимость перезапуска, допустимые значения и дополнительное описание при наличии. Null отображается как «—», пустая строка — как «(пустая строка)». Числа не конвертируются; единицы приведены отдельно.

### Документация QHB

**420 из 436 параметров** связаны с [документацией QHB 1.5.3](https://repo.quantom.info/qhb/std-1/doc/1.5.3/ru/Configuration/runtime-config.html). Ссылка QHB показывается первой, перед PostgreSQL и блогом. В JSON она хранится в `qhb_documentation_link` с полями `title` и `url`.

Проверено 2 ноября 2026 года: 19 страниц главы конфигурации, её оглавление и 9 дополнительных страниц руководства. Для 406 параметров найдены точные заголовки; ещё 14 параметров сопоставлены с проверенными разделами об автономных транзакциях, метриках, CDC, кеше планов, планировщике, профилировании, queryid и управлении ресурсами. Все якоря проверены в загруженном HTML; адреса привязаны к версии 1.5.3.

Каталог [data/qhb_documentation.json](data/qhb_documentation.json) содержит ссылки, способ сопоставления, проверенные страницы, повторные определения и 16 параметров без найденного описания. Для них ссылка QHB не добавляется. При повторном определении используется первый заголовок на странице. Случайные упоминания параметров не используются как описания. Дополнительно проверен поисковый индекс руководства для поиска описаний вне главы конфигурации.

### Официальная документация

**358 параметров** связаны с описаниями в [документации PostgreSQL current](https://www.postgresql.org/docs/current/runtime-config.html). У остальных 78 поле отсутствует. В JSON ссылка хранится как `documentation_link` с полями `title` и `url`. В карточке она расположена перед статьями блога и не добавляет значок на карту.

Все адреса начинаются с `https://www.postgresql.org/docs/current/` и содержат проверенный якорь. На 30 октября 2026 года `current` соответствует PostgreSQL 18. Проверены 18 страниц главы Server Configuration. Сопоставление основано на точных именах в определениях параметров. Общие определения `debug_print_*` и `log_*_stats` используют существующие общие якоря. Для `ssl_ecdh_curve` ссылка ведёт на `ssl_groups`, где явно описано прежнее имя; переименование отмечено в заголовке ссылки.

Каталог [data/postgresql_documentation.json](data/postgresql_documentation.json) содержит соответствия, проверенные страницы, версию на дату проверки и параметры без найденного описания. Удалённые и специфичные для сборки настройки не получают предположительных ссылок. Адрес `/docs/current/` следует за новыми стабильными выпусками; сохранённые соответствия требуют обновления при изменении документации.

### The Build

**257 параметров** связаны с **198 статьями** [блога Christophe Pettus](https://thebuild.com/blog/): всего **322 связи**. Наличие статьи обозначается красной четырёхлучевой ромбовидной звёздочкой в форме favicon блога. Несколько статей об одном параметре выводятся отдельными ссылками.

Проверено 30 октября 2026 года: пройдены все 49 страниц доступного архива и загружены тексты 484 статей, включая 192 статьи серии «All Your GUCs in a Row». Учтены статьи вне серии, обновление об `array_nulls` и общие статьи о семействах `recovery_target`, `geqo` и `debug_*`. Случайные упоминания настройки не считаются статьёй о ней.

Каталог [data/thebuild_articles.json](data/thebuild_articles.json) сохраняет оригинальные заголовки, канонические URL, списки параметров и способ сопоставления. Параметры статьи, отсутствующие в текущем справочнике, перечислены отдельно. Тексты статей в проект не включены. В JSON параметра ссылки находятся в массиве `blog_links`, каждый элемент содержит `title` и `url`.

Карта не обращается к сайтам при открытии. Ссылки проверяются по разрешённому HTTPS-адресу, заголовки выводятся как текст. Внешние страницы открываются с `noopener noreferrer`.

## Файлы и пересборка

| Файл | Назначение |
| --- | --- |
| [pg_settings_full.html](pg_settings_full.html) | Основная автономная карта |
| [pg_settings.json](pg_settings.json) | Данные параметров и внешние ссылки |
| [tools/templates/map.html](tools/templates/map.html) | Шаблон оформления и взаимодействий для генератора |
| [tools/build_full_map.py](tools/build_full_map.py) | Генерация полной карты из JSON и шаблона |
| [tools/apply_blog_links.py](tools/apply_blog_links.py) | Применение проверенного каталога статей |
| [tools/apply_qhb_documentation_links.py](tools/apply_qhb_documentation_links.py) | Применение или обновление каталога QHB 1.5.3 |
| [tools/apply_documentation_links.py](tools/apply_documentation_links.py) | Применение или обновление каталога документации |

Для пересборки нужен Python 3 со стандартной библиотекой. Из корня репозитория:

```sh
python3 tools/build_full_map.py
```

Повторно применить сохранённые каталоги без сети и пересобрать карту:

```sh
python3 tools/apply_blog_links.py
python3 tools/apply_documentation_links.py
python3 tools/apply_qhb_documentation_links.py
python3 tools/build_full_map.py
```

Обновить каталог по текущей официальной документации (нужны `curl` и доступ к `www.postgresql.org`):

```sh
python3 tools/apply_documentation_links.py --refresh
python3 tools/build_full_map.py
```

Обновить каталог QHB 1.5.3 по опубликованному руководству (нужны `curl` и доступ к `repo.quantom.info`):

```sh
python3 tools/apply_qhb_documentation_links.py --refresh
python3 tools/build_full_map.py
```

Скрипты проверяют соответствия до изменения данных и сохраняют остальные свойства параметров. Обновление каталога блога новыми статьями требует отдельной проверки источника: `apply_blog_links.py` не обходит блог автоматически.

## Проверки и следующие шаги

Проверки каталога QHB без сети:

```sh
python3 -m unittest discover -s tests -p test_qhb_documentation.py
```

Браузерная регрессионная проверка также проверяет все 420 ссылок QHB, их порядок в карточках и безопасное открытие в новой вкладке.

В Chromium проверены раскрытие веток, поиск, приближение, выравнивание, перетаскивание, фильтры групп, всплывающие панели, подсказка, все 358 ссылок на документацию и 322 ссылки на блог, отсутствие сетевых запросов при открытии и узкий экран. Проверены существование якорей, воспроизводимость генерации и сохранность исходных характеристик параметров и ссылок при обновлении каталогов.

Регрессионная проверка сохранения состояния (нужны Python-пакет `playwright` и Chromium по пути `/usr/bin/chromium`):

```sh
python3 tests/test_saved_state.py
```

Проверяются восстановление координат после перемещения, раскрытие веток, видимость групп, перезагрузка и повторное открытие страницы, сброс карты, экспорт и импорт настроек, отклонение ошибочных файлов, повреждённое и недоступное хранилище. Для просмотра и генерации карты эти зависимости не нужны.

Следующие этапы: импорт пользовательского JSON из интерфейса и логические связи между параметрами.
